How to get auth.json
  1. On your local machine, find Codex auth: ${CODEX_HOME:-$HOME/.codex}/auth.json
  2. Upload that file here. It is encrypted at rest and only decrypted into a temporary directory while refreshing limits.
  3. For Claude, upload the Claude Code login file: ~/.claude/.credentials.json
  4. For a public deployment, use a strong site password and rotate the login if you no longer trust the server.
